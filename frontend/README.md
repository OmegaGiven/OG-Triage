# frontend

React + TypeScript + Vite review UI (Phase 6) — denial queue + detail/review
views over the Phase 5 FastAPI backend. See the repo root `README.md`'s
"Phase 6 — Frontend (Queue + Review)" section for the full write-up (stack,
design system, views, and live-verification notes).

## Quick start

```bash
npm install
cp .env.example .env.local   # VITE_API_BASE_URL=http://localhost:8000/api
npm run dev
```

Requires the Phase 5 backend running at that URL (see root README for
backend setup).
